Indian Vocal Synth - Swar Editor

X-axis: Time | Y-axis: Tone (Swar)

  • Click on empty space to add a curve point
  • Shift+Click to add a square Swar point
  • Drag points to move them (snaps to grid)
  • Drag handles to adjust curves
  • Click on curve to add a point on it
  • Ctrl+Click on curve point to select/deselect
  • Click on Swar point to enter swar change mode
  • Arrow keys in swar mode: Up/Right = higher swar, Down/Left = lower swar
  • Escape/Enter to exit swar change mode
  • Delete key to delete selected points
  • Drag selected to move multiple points
  • Toggle Grid button to show/hide grid
  • Toggle Handles button to show/hide control handles
  • Ctrl+Z (or Cmd+Z) to undo
  • Ctrl+Y or Ctrl+Shift+Z to redo
